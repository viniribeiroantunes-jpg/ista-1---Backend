# Exercícios em PHP

## Sobre o projeto

Este repositório contém exercícios desenvolvidos durante as aulas de Desenvolvimento de Sistemas, utilizando a linguagem PHP.

Os exercícios trabalham conceitos básicos de programação, como:

- Variáveis
- Operadores matemáticos
- Estruturas condicionais
- Estruturas de repetição
- Arrays
- Funções
- Cálculos e classificações

## Exercícios

### 1. Compra com desconto
Calcula o valor total de uma compra e aplica 10% de desconto quando o valor for igual ou superior a R$ 200,00.

### 2. Aprovação do aluno
Verifica se o aluno foi aprovado considerando a média final e a quantidade de faltas.

### 3. Tabuada
Exibe a tabuada de um número de 1 a 10 utilizando a estrutura `for`.

### 4. Notas da turma
Armazena as notas de 5 alunos em um array e utiliza `foreach` para calcular a média, a maior e a menor nota.

### 5. Cálculo do IMC
Possui uma função para calcular o IMC e utiliza estruturas condicionais para apresentar a classificação.

O objetivo deste projeto é praticar os principais conceitos da programação em PHP e desenvolver a lógica de programação por meio de exercícios práticos.
